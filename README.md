# skills

Claude Code skills I tend to use. Each directory is a self-contained skill that can be symlinked to the current project. 

## What's here

| Skill | What it does |
|-------|-------------|
| [code-review](./code-review) | Reviews staged changes for bugs, security holes, performance, comment bloat, and design problems. Reads the project's `DEVELOPMENT.md` and any language-specific rules in this repo |
| [frontend-design](./frontend-design) | Builds frontend interfaces that look designed rather than generic, without the usual "AI slop" look ([forked from claude-code](https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design/skills/frontend-design)) |
| [humanizer](./humanizer) | Removes signs of AI-generated writing so text reads as if a person wrote it ([submodule](https://github.com/blader/humanizer)) |
