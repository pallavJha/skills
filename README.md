# skills

Claude Code skills I tend to use. Each folder is a self-contained skill you can be symlinked to the current project. 

## What's here

| Skill | What it does |
|-------|-------------|
| [code-review](./code-review) | Reviews staged changes for bugs, security holes, performance, comment bloat, and design problems. Reads the project's `DEVELOPMENT.md` and language-specific rules available in this repo |

## Install

Symlink the ones you want:

```bash
ln -s /path/to/skills/code-review ~/.claude/skills/code-review
```
